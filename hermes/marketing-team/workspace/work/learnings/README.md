# Learnings

Kakashi viết ở đây. Thư mục này nằm trong workspace riêng: file bài học có thể có tên khách và số thật, nên **không** đưa lên bundle công khai; chỉ file README này đi theo bundle.

## File
| File | Là gì |
|---|---|
| `<YYYY-Www>.md` | Bài học một tuần. Shikamaru, Lelouch và Tsunade đọc file mới nhất trước khi lập plan |
| `c<số>-<slug>.md` | Bài học một campaign, viết khi campaign đóng hoặc Ông Chủ yêu cầu |

File của tuần đã qua không sửa; điều mới viết vào file tuần hiện tại.

## Một file (tối đa khoảng 400 từ)
```
# Learnings <YYYY-Www> (hoặc campaign c<số>-<slug>)

## Đã thử
<việc đã làm, một dòng mỗi việc, kèm file hoặc link>

## Kết quả
<số hoặc nhận xét chất lượng, mỗi dòng có nguồn và ngày. Chưa có số: ghi `chưa có số`>

## Giữ / Dừng / Thử
- Giữ: <...>
- Dừng: <...>
- Thử: <...>

## Đề xuất đổi brain
<file brain, đổi gì, vì sao, ai quyết: giọng là Yugi, plan là Shikamaru hoặc Lelouch. Hai file brain mâu thuẫn thì liệt kê ở đây, không chọn bên>

## Điểm chấm
<tối đa 10 bài Ông Chủ đã duyệt: file, 5 tiêu chí mỗi tiêu chí 1 / 3 / 5>
```
