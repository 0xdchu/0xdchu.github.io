# Ví dụ tốt

Ví dụ chỉ vào đây khi Ông Chủ trả lời `mẫu tốt <file>` trong topic Kakashi cho một bài Ông Chủ đã duyệt. Kakashi không tự chọn, không viết lại, không sửa chữ nào.

## Thư mục theo loại
| Thư mục | Loại |
|---|---|
| `social-post/` | Bài social (LinkedIn, Facebook, Instagram, Twitter) |
| `video-script/` | Kịch bản video ngắn |
| `article/` | Bài website |
| `banner/` | Banner, email, hero card |

## Một ví dụ là một file
Tên `<YYYY-MM-DD>-<slug>.md`, đầu file có:

```
Nguồn:            <đường dẫn file gốc trong work/>
Ông Chủ duyệt:    <ngày>
Nền tảng / loại:  <...>
Vì sao tốt:       <lời Ông Chủ, chép nguyên; không có thì (trống)>
```

Dưới đó là bài đúng nguyên văn bản đã duyệt. Ví dụ đã vào không bị sửa; thay bằng ví dụ mới thì ghi file cũ là "thay bởi <file>" trong learnings, không xoá lặng lẽ.

## Thư mục còn trống
Thư mục loại nào chưa có file ví dụ thì role nói "chưa có ví dụ cho <loại>" và không tự lấy bài khác làm ví dụ.
